# Design System

Farben, Typografie, Komponenten und Spacing-Regeln für das Projekt.

---

## Farben

| Token | Hex | Verwendung |
|---|---|---|
| `primary` | `#2e6da4` | Buttons, Links, CTAs |
| `primary-dark` | `#1e4d73` | Hover States |
| `bg` | `#ffffff` | Seitenhintergrund |
| `bg-subtle` | `#f6f8fa` | Karten-Hintergrund |
| `text` | `#1c1e21` | Fließtext |
| `border` | `#d0d7de` | Rahmen, Divider |

---

## Typografie

| Element | Schrift | Größe | Gewicht |
|---|---|---|---|
| H1 | System-UI | 2rem | 700 |
| H2 | System-UI | 1.5rem | 600 |
| Body | System-UI | 1rem | 400 |
| Code | Monospace | 0.875rem | 400 |

---

## Spacing

Das Projekt nutzt ein 8px-Raster:

| Token | Wert |
|---|---|
| `xs` | 4px |
| `sm` | 8px |
| `md` | 16px |
| `lg` | 24px |
| `xl` | 32px |
| `2xl` | 48px |
