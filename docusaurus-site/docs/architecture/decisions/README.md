# Architecture Decision Records (ADRs)

ADRs dokumentieren wichtige Architekturentscheidungen — warum eine Entscheidung getroffen wurde, welche Alternativen es gab, und welche Konsequenzen sie hat.

## Vorlage

Erstelle eine neue Datei `docs/architecture/decisions/NNNN-titel.md`:

```markdown
---
title: "ADR-NNNN: Titel der Entscheidung"
date: YYYY-MM-DD
status: "Vorschlag | Akzeptiert | Veraltet | Abgelöst durch ADR-XXXX"
---

# ADR-NNNN: Titel

## Status

Akzeptiert

## Kontext

Warum musste diese Entscheidung getroffen werden?

## Entscheidung

Was wurde entschieden?

## Konsequenzen

Welche Auswirkungen hat die Entscheidung (positiv und negativ)?
```
